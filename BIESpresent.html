Set up tonight

Set this up before doors open, then start the night. You can come back any time while the event is running — press E, or move the mouse and click Edit tonight — and changes reach the screen straight away. Everything is saved in this browser, so a refresh loses nothing. Nothing the room sees ever needs the internet — the only thing here that reaches out is looking up the name of a YouTube track, and only if you paste one in.

—

Code convention from the ops schedule: prefix + YYYYMMDD. SN social night · NN networking night · MK market · MM mastermind · EX excursion · PG program.

Paste an itinerary instead of typing it optional

A shortcut for starting a night, not a replacement for the list below — everything stays editable by hand afterwards. Copy the run of show out of Notion, a Google Doc or a spreadsheet and drop it in, one segment per line. It reads clock times, time ranges, title | minutes, table rows, bullets and numbered lists. Durations come from the gaps between times unless a range or an explicit length says otherwise.

Times are worked out from the start time and each segment's length, so changing one length moves everything after it. Drag the handle to reorder.

Ends at —

QR panel

The code is generated on this machine, so it works with the venue wifi down. Leave both the link and the image empty to hide this panel.

Or use your own QR image

Upload a PNG, JPG or SVG and it replaces the generated code. Keep the link filled in anyway if you want the address printed under the caption. SVG stays sharp at any size; a bitmap should be at least 600×600.

Partners & sponsors

The name is used as the image's alt text either way. Tick Show name only for logos that are a symbol with no wordmark — captioning every logo makes the panel noisy. Logos are shrunk to fit the browser's storage budget; pale or white ones read best on the dark screen.

What's coming up

One event per line: date | name | detail — e.g. Sep 25 | Oriente Tour | 3 days. Ops codes are stripped automatically — they never go on the screen.

Rotation

Speakers' decks

Load a deck as slide images and you can drive it from here — next, back, jump to any slide, countdown overlaid. Load it as a PDF and it goes up exactly as the speaker exported it, but the pages have to be turned in the PDF viewer itself. Both come out of dropping the original into decks/inbox and running Convert Decks.

Select every slide image of one deck together and they become that deck, in filename order — which is why the converter numbers them. A .pptx or .key is logged so it is not forgotten, but no browser can display one: it sits here marked needs converting.

YouTube queue

A separate queue from the audio files above, and it has to be: these tracks play in a YouTube window this page cannot see into, so nothing can hand over from one list to the other. Pick a source per stretch of the night. Paste links — one per line, watch links, youtu.be links or bare ids all work.

Finding a track

Searching inside this window is not possible — YouTube's search needs an API key, and a key baked into a file that gets emailed around is a key that leaks. This opens a normal YouTube tab instead; copy the link back into the box above.

Hand this night to someone else

Export saves a small .json file. Whoever is carrying the laptop opens this screen, imports it, and has the exact same night.
